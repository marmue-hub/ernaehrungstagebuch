Technische Rahmenbedingungen:
- muss auf dem iphone laufen, aber es  liegt weder ein mac noch ein entwickleraccount vor
- synchronisation der eingegebenen daten im lokalen wlan
- zentrale Datenhaltung auf server im lokalen lan, z.b. docker container
- lokaler server muss ebenfalls implementiert werden. domain: wiegehts.x73.eu

Fachliche Funktionen:
- Eingabe von Essen und Uhrzeit (auch nachträgtlich). Default-Wert: aktuelle Uhrzeit
- Eingegebenes Essen das nächste Mal im Rahmen einer Liste vorschlagen
- Eingabe von Synmptomen: Bauchweh, Übelkeit, Kopfschmerzen: Skala von 1-5
- Eingabe von Gesamtwohlbefinden: 3er Skala mit Smilies
- Erinnerungsfunktion 1h und 4h nach dem Essen
